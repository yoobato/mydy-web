어떤 일을 도와주나요?

출생증명서의 영문 항목과 한글 번역문을 번갈아 확인하면서 서식을 맞추는 일을 줄이기 위해 만들었습니다. 성·이름, 날짜, 출생지, 부모 정보, 등록관과 번역자 이름을 정해진 위치에 넣고 PDF로 저장합니다. 공개 서비스는 현재 알버타 출생증명서의 부모 정보 포함형을 기준으로 합니다.

자동 번역이나 문서 인식 도구는 아닙니다. 원본의 내용을 읽고 사용자가 직접 한글을 입력해야 합니다. 화면에 표시되는 예시는 입력 방법을 설명하기 위한 것으로, 자신의 원본에 맞게 작성해야 합니다.

준비할 것과 작성 범위

  • 부모 정보가 포함된 원본 출생증명서를 준비합니다.
  • 아이와 부모의 성명·출생지를 한글로 어떻게 쓸지 확인합니다.
  • 서명 아래 등록관 이름은 한국어 발음대로 직접 옮깁니다.
  • 번역문을 작성한 사람의 한글 이름을 준비합니다.

등록번호와 증명서 번호는 이름과 달리 원본의 영문·숫자를 확인해 입력합니다. 서식 번호를 원본과 대조하고, 원본에 없는 값을 예시에서 가져오지 마세요.

입력에서 출력까지

  1. 원본과 같은 항목을 찾아 성·이름과 출생지를 입력합니다.
  2. 생년월일·등록일·발급일을 달력에서 선택하고 성별을 지정합니다.
  3. 부모 정보와 등록관·번역자 이름을 채웁니다.
  4. 미리보기에서 누락·오타·번호·날짜를 원본과 대조합니다.
  5. PDF를 저장한 뒤 Letter 용지에 출력하고 번역자 이름 옆에 서명합니다.

날짜 순서 검사나 필수값 검사는 입력 실수를 찾기 위한 기능입니다. 모든 검사를 통과해도 번역 정확성이나 서류 수리가 확인된 것은 아닙니다.

입력 정보와 제출 전 확인

입력값과 PDF 생성은 브라우저 안에서 처리하며 양식 내용을 서버에 저장하지 않습니다. 새로고침하면 입력 내용이 사라집니다. 다운로드한 PDF에는 개인정보가 들어가므로 공용 기기에서는 저장 위치와 파일 정리를 확인하세요. 광고·이용 통계에 관한 설명은 번역 도구의 안내도 함께 읽어 주세요.

정부·영사관의 공식 서비스가 아닙니다. 제출 서류의 종류와 최신 요건은 주밴쿠버 총영사관 출생신고 안내에서 확인합니다. 원본과 번역문은 별개 서류이며 이 도구가 출생신고서를 대신 작성하거나 신고를 접수하지는 않습니다.
