What does it help with?

This tool reduces the work of moving between an English birth certificate and a Korean translation layout. It places names, dates, birthplaces, parent information, the registrar and the translator into a PDF. The public version currently follows Alberta certificates with parentage information.

It does not perform OCR or automatically translate a certificate. You read the original and enter the Korean wording yourself. Placeholder examples explain the fields; they are not values to copy into a real translation.

Before you start

  • Have the original certificate with parent information ready.
  • Check the Korean spelling of the child’s and parents’ names and birthplaces.
  • Transcribe the registrar’s name below the signature into Korean yourself.
  • Have the translator’s Korean name ready.

Registration and certificate numbers are identifiers: copy the letters and digits from the original. Compare the form code too. Do not take example values from placeholders when they are not on your document.

From input to print

  1. Match each field to the original and enter the child’s names and birthplace.
  2. Select birth, registration and issue dates, then choose the sex shown on the certificate.
  3. Complete parent details and the registrar’s and translator’s names.
  4. Compare the preview against the original for missing details, spelling, numbers and dates.
  5. Save the PDF, print on Letter paper and sign beside the translator’s name.

Required-field and date-order checks help catch input mistakes. Passing them does not establish translation accuracy or acceptance by the receiving office.

Data handling and submission

Form values and PDF generation stay in the browser; the form is not saved to a server. Refreshing clears the entries. Downloaded PDFs contain personal information, so check the save location and remove files from shared devices. Read the tool’s own advertising and analytics notices as well.

This is not a government or consular service. Check current document requirements in the Vancouver consulate’s birth-registration instructions (Korean). The original certificate and its translation are separate documents. The tool does not complete or submit the Korean birth-registration application.
