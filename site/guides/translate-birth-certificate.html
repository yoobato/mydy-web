출생증명서 번역문 작성·PDF 출력 가이드

원본 대조부터 한글 입력, 날짜 확인, PDF 저장과 자필 서명까지 순서대로 살펴봅니다.

이 글에서 살펴볼 내용1. 원본과 번역 대상 구분하기2. 이름·출생지·번호 입력하기3. 날짜와 긴 입력값 확인하기4. PDF 저장·출력·서명제출 직전 다시 확인할 것

1. 원본과 번역 대상 구분하기

먼저 원본에 부모 정보가 포함되어 있는지 확인합니다. 번역 도구의 공개 버전은 알버타 서식을 기준으로 하므로 다른 주의 문서를 억지로 같은 서식에 맞추지 않습니다. 출생증명서 한글 번역문과 한국 출생신고서는 다른 문서입니다.

작성할 때는 원본을 옆에 놓고 항목 하나씩 대응시키는 것이 좋습니다. 이름·번호·날짜처럼 비슷해 보이는 값은 기억으로 채우지 말고 직접 대조하세요. 사용 예시는 실제 가족 정보 대신 김하늘, 김예시 같은 가상 이름으로 설명합니다.

2. 이름·출생지·번호 입력하기

Surname에는 아기의 성, Given Names에는 성을 제외한 이름을 한글로 입력합니다. 예를 들어 성이 김이고 이름이 하늘이라면 두 칸을 나누어 작성합니다. 영문 등록관 이름은 한국어 발음으로 직접 입력하며 자동 이름 제안은 제공하지 않습니다.

출생지에는 원본의 도시를 확인해 한글로 옮깁니다. 알버타 양식의 모·부 성명과 부모 출생 국가도 서로 바뀌지 않게 확인합니다. 등록번호와 하단 증명서 번호는 서로 다른 값일 수 있으므로 같은 번호를 두 번 넣지 말고 원본의 위치를 살펴보세요.

3. 날짜와 긴 입력값 확인하기

생년월일, 등록일, 발급일은 각각 다른 의미를 가집니다. 월·일 순서를 확인한 뒤 달력에서 선택합니다. 도구는 생년월일 ≤ 등록일 ≤ 발급일의 순서와 실제 존재하는 날짜를 검사합니다. 오류가 나면 통과시키려고 임의 날짜를 넣지 말고 원본의 어느 날짜를 옮겼는지 다시 확인하세요.

긴 성명이나 출생지는 PDF에서 글자가 작아질 수 있습니다. 원본에 필요한 내용을 임의로 줄이기보다 미리보기에서 읽을 수 있는지 확인하고, 문제가 있으면 출력 전에 운영자에게 가상 예시로 문의해 주세요.

4. PDF 저장·출력·서명

  1. 번역자 이름까지 입력한 뒤 미리보기를 엽니다.
  2. 원본과 번역문을 위에서 아래로 대조합니다. 필수 입력 진행률은 정확성 점수가 아닙니다.
  3. PDF 다운로드를 누르고 저장된 파일을 다시 엽니다.
  4. 용지를 Letter(8.5 × 11인치)로 선택하고 인쇄 미리보기에서 잘림 여부를 확인합니다.
  5. 번역자 이름 옆 (인) 위치에 자필 서명합니다.

글꼴이 깨지거나 미리보기가 비어 있으면 연결 상태를 확인하고 PDF를 내려받아 별도 PDF 뷰어로 열어 봅니다. 다운로드가 실패하면 브라우저의 다운로드 차단 안내와 저장 권한도 확인하세요. 새로고침하면 양식 입력이 사라지므로 먼저 필요한 내용을 별도로 확인해 두세요.

제출 직전 다시 확인할 것

원본과 번역문의 이름·날짜·번호, 발급기관 표기, 번역자 이름과 자필 서명을 확인합니다. 최신 구비서류와 원본 반환 여부는 영사관 공식 안내를 따릅니다. 이 가이드는 도구 사용법이며 개별 서류의 접수 가능 여부를 판단하지 않습니다.
